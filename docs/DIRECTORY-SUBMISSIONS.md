## Canonical listing copy

Shopify Multi-Store MCP connects Claude, Codex, Cursor, VS Code, and other MCP clients to multiple Shopify Admin stores through one secure server. Search products across stores, compare catalogs, prices, inventory, and collections, run portfolio reports, and make guarded updates without switching connections.

Install command:

```bash
npx -y shopify-multi-store-mcp-server setup
```

MCP start command:

```bash
npx -y shopify-multi-store-mcp-server start
```

Use the MIT license, the `shopify` and `e-commerce` categories, and the repository README image when a directory accepts a logo or screenshot.
